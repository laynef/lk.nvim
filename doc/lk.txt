1. INTRODUCTION                                            *sage-introduction*

sage.nvim integrates the sage AI CLI into Neovim. It provides:

- Code explanation in a floating window
- In-place refactoring (writes files via sage run)
- Test generation for the current file
- Error fixing on selected code
- A floating chat panel
- Git commit message generation (integrates with fugitive/neogit)
- Model switching (cloud:*, openrouter:*, ollama:*, llama_cpp:*)

Requires: pip install local-keep-ai-cli && sage login

==============================================================================
2. INSTALLATION                                            *sage-installation*

lazy.nvim: >
    {
      "laynef/sage.nvim",
      config = function()
        require("lk").setup()
      end
    }
<

vim-plug: >
    Plug 'laynef/sage.nvim'
<

==============================================================================
3. SETUP                                                        *sage-setup*

Minimal: >
    require("lk").setup()
<

Full: >
    require("lk").setup({
      model        = "",          -- blank = read from ~/.sage/config.json
      context_lines = 50,
      binary       = "",          -- blank = auto-discover sage binary
      keymaps = {
        explain  = "<leader>se",
        refactor = "<leader>sr",
        tests    = "<leader>st",
        fix      = "<leader>sf",
        chat     = "<leader>sc",
        commit   = "<leader>sg",
        run      = "<leader>sx",
        models   = "<leader>sm",
      },
    })
<

==============================================================================
4. COMMANDS                                                    *sage-commands*

:LKExplain                                                   *:LKExplain*
    Explain the current selection or surrounding context.
    Works in visual and normal mode.

:LKRefactor                                                 *:LKRefactor*
    Refactor the selected code and write the result to the file.

:LKTests                                                       *:LKTests*
    Generate unit tests for the current file.

:LKFix                                                           *:LKFix*
    Fix errors in the selected code.

:LKChat                                                         *:LKChat*
    Open a floating chat panel. Press <CR> on the input line to send.
    Press q to close.

:LKCommit                                                     *:LKCommit*
    Generate a git commit message from the staged diff.
    Integrates with fugitive and neogit if installed.

:LKRun                                                           *:LKRun*
    Prompt for a task and run it with the sage agent (file edits, tests).

:LKModels / :LKModel                                       *:LKModels*
    List available models and select one interactively.

==============================================================================
5. KEYMAPS                                                      *sage-keymaps*

Default keymaps (all in normal and visual mode):

    <leader>se  SageExplain
    <leader>sr  SageRefactor
    <leader>st  SageTests
    <leader>sf  SageFix
    <leader>sc  SageChat
    <leader>sg  SageCommit
    <leader>sx  SageRun
    <leader>sm  SageModels

Override in setup({ keymaps = { explain = "<leader>ai", ... } }).
Set any key to "" to disable that keymap.

==============================================================================
6. CONFIGURATION                                               *sage-config*

All options with defaults: >

    require("lk").setup({
      model         = "",     -- model ID (e.g. "cloud:qwen3-coder")
      context_lines = 50,     -- lines of context sent with code actions
      binary        = "",     -- explicit path to sage binary
      keymaps       = { ... } -- see |sage-keymaps|
    })
<
